# 审计报告复核技能

版本：2.1.0

检查审计报告中的财务报表、附注及文字，发现加总、勾稽、口径和披露问题，输出可追溯的 Excel 与 Markdown 复核记录。

**运行这个技能的当前 agent 负责语义理解和终审。** 本地程序负责提取、确定性计算、保存进度及导出，不调用另一套外部模型，不读取模型密钥。旧模型入口及参数已清除。

## 如何使用

在支持本地技能的 agent 中启用本目录，直接提出需求，例如：

> 用 audit-report-checker 复核这份审计报告，检查四表、附注和文本，保留问题出处。

agent 会复用本次对话已确认的信息，询问尚缺的资料范围、主体、期间、适用准则、检查深度，以及当前模型的上下文容量。需要选择文件时使用宿主的 Windows 选择窗口；已有文件路径不重复询问。

完整执行要求见 [SKILL.md](SKILL.md)，无需用户手工填写程序参数或结构文件。

## 128K 与 1M

| 当前模型容量 | 每批源材料默认上限 | 执行方式 |
|---|---:|---|
| 128K | 20,000 字符 | 分批检查，保存进度并续作 |
| 1M | 80,000 字符 | 使用较大批次，执行相同复核标准 |
| 不清楚 | 20,000 字符 | 按128K保守安排 |

这些是材料字符限额，不是精确的模型 token 计量。容量只改变批次大小，不缩减检查范围。大表按完整原始行分片，每片携带首部、表头、章节、已声明口径及原始行号；长文字按区间分片。单行或背景超出预算时明确要求有依据地分解，不截断资料。

## 复核范围

- 四表内及相互勾稽，包括利润链、汇率影响、现金构成和两期权益变动。
- 报表与附注的同主体、同期间、同币种、同口径核对。
- 附注横加竖加、变动表、原值、准备与净值关系。
- 文本、公司名称、编号、单位、前后矛盾及适用披露。
- 用户本次要求及明确授权长期保存的自定义规则。

合并与母公司、两期、金额与比例、余额与净值分别处理。仅有附注时按实际资料判断适用范围，不虚构四表。业务规则及官方依据见 [业务规则](references/rules.md)。

## 工作流程与资料保护

1. 登记来源文件，保留原件路径与 SHA-256，提取全文、表格及未识别清单。
2. 当前 agent 阅读原文，声明结构、列角色、主体期间及金额单位；完整列出应检跨表关系。
3. 程序按明确来源和公式计算，使用 Decimal，不用模型心算替代算术。
4. 当前 agent 逐批核实计算及业务适用性，填写原文引用、依据和结论。
5. 核对应检清单、完成终审，再生成结果；导出前重新校验原件版本。

原始资料只读。输出不能覆盖原件、关键输入或进度；覆盖已有产物前备份并校验。进度采用完整写入后原子替换，中断不截断原进度。未执行对象可重新提交，同一已提交结果重复回填保持幂等；输入或规则变更后旧结论失效。

应检业务关系是否完整，仍由当前 agent 根据原文负责。程序校验已声明关系是否全部执行及计算一致，不能用“读过全部表格”代替“已检查全部适用关系”。

## 文件格式与识别缺口

- DOCX：保留正文、原始表格、制表符、换行、内容控件及可得的页眉页脚出处。
- 文本型 PDF：逐页提取，保留实际物理页码。
- XLSX/XLSM：读取原始值并检查公式缓存；无缓存时保留未执行，不擅自重算或补零。
- 图片、扫描页及不可读部分：由当前 agent 使用宿主视觉核实，或登记需补充的资料。
- 旧 XLS/DOC 等不能可靠处理的格式：登记来源和未执行原因，请提供可读版本，不静默略过。

默认本地提取。可选云端 OCR 仅在用户明确授权本次文件或PDF页范围后执行；失败时保留已完成的本地提取。详见 [提取说明](references/extraction.md) 和 [可选OCR说明](references/mineru_usage.md)。

## 交付结果

Excel包含7张表：摘要、报表内勾稽、表注勾稽、附注内勾稽、横加竖加、文本格式、检查项，同时生成Markdown复核记录。结果保留来源、原始金额、公式、差额及终审依据。

结论分为：通过、确认错误、待核实、未执行、不适用、已排除误报。只有实际终审通过计入通过，其他状态分别统计。空结果、缺对象、缺应检关系或缺终审不能宣称完成。计数按检查对象统计，同一错误可能涉及多条关系，应说明同源情况，不重复当作独立错误。

## 运行与验证

已验证环境为 Windows、本机 Python 3.14，使用已安装的 python-docx、openpyxl、pdfplumber、PyMuPDF；测试另用 pytest、reportlab。无需模型客户端依赖，默认不安装额外软件。

维护者可在技能根目录运行回归；本机解释器示例：

```powershell
$OutputEncoding = [Console]::OutputEncoding = [Text.Encoding]::UTF8
& 'C:\Users\27651\AppData\Local\Programs\Python\Python314\python.exe' -X utf8 -B -m pytest -q tests -p no:cacheprovider
```

2.1.0已完成16项审计问题整改，126项自动测试通过；含9张表的完整Word合成样例在128K和1M两档得到一致的应检对象、金额和结论，并发现预设的1元差异。

验证使用合成资料，尚未以真实客户报告、所有宿主模型或云端OCR实测替代验收。适用准则、取数口径和最终业务判断须结合实际报告核实。
