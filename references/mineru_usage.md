# 图片与可选OCR

默认不调用云端OCR，不自动安装或上传。当前agent优先使用宿主视觉，不能读取则留下原页/原图路径、缺少内容和对结果的影响。

确需MinerU先说明将上传的具体文件或PDF物理页范围，取得本次明确授权。已有CLI不等于获得授权；不得扩大到文件夹或自动查找密钥。--allow-cloud-ocr仅运行已安装CLI，不负责安装、登录或配置。
授权后Git Bash示例：
```bash
"$解释器" -X utf8 -B "$技能/scripts/parse_report.py" "$资料" -o "$工作" --allow-cloud-ocr --ocr-pages 3-7
```
ocr-pages为PDF物理页，从1开始，先本地拆授权页再上传；非PDF不用页参数。目录上传参数被拒绝。
OCR只是补充文字；当前agent逐格核对原页的负号、小数、合并格、单位与位置。确认后把可信补充并入本地提取产物，保留原文、识别来源及依据，再重新建任务。原缺口不自动消除，估算页码不能冒充真实页码。本次整改未实测云上传。
